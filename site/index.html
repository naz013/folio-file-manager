Folio GitHub

A calm place for your files.

Folio is a lightweight, Finder-inspired file manager for Windows, macOS and Linux. Tabs, color tags, drag and drop, a space breakdown and cleanup that always goes through the trash.

Download Folio Windows, macOS and Linux

Download

  • Windows

    Installer (.exe), with automatic updates.

  • macOS

    One disk image (.dmg) for Apple silicon and Intel.

  • Linux

    AppImage, .deb and .rpm packages.

Pick your file from the latest release. Folio updates itself after that.

Made for people who live in their files

  • Fast

    Large folders scroll smoothly. Lists are virtualized, so size doesn't slow it down.

  • Tabs and color tags

    Keep several places open and mark files with colors you can find again.

  • Safe by design

    Deletes go to the Recycle Bin or Trash. Cleanup never removes anything permanently.

  • See where space goes

    A space breakdown shows which folders are heavy, before you clean up.

  • Light and dark

    Follows your system theme, with a design that stays out of the way.

  • On every desktop

    The same app on Windows, macOS and Linux. See what is next on the roadmap.
